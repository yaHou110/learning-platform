```powershell

curl.exe -sS http://localhost:3000/api/health
# → {"status":"ok","db":true,"timestamp":"2026-07-15T20:28:03.185Z"}

# 2) CSRF token
curl.exe -sS -c .tmp/cookies.txt http://localhost:3000/api/auth/csrf
# → {"csrfToken":"35223953d4b1887ed317e0d8f301a1ff0e19877ad048039badf7b64331289be8"}

# 3) Login (tenantSlug is required by the Auth.js credentials config)
curl.exe -sS -b .tmp/cookies.txt -c .tmp/cookies.txt -i -X POST \
```

2. Added security headers via `next.config.mjs` `headers()` (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy)
3. Added `poweredByHeader: false` to next.config.mjs
4. Created `apps/web/src/lib/env.ts` — centralized env validation with production throw + dev warning
5. Updated `auth.ts` and `middleware.ts` to use shared `env` helper

7. Added `dir="rtl"` to login page `<main>` for consistency with dashboard
