## Why this is a finding

While completing the M3 evidence gap, a routine `pnpm audit` was run as part of the M4 "secret management / vulnerability scanning" pre-work. It surfaced **28 known vulnerabilities** in the current dependency set, almost entirely in the framework layer (`next@15.0.3` and `next-auth@5.0.0-beta.25`).

## Residual issues (2 advisories)

### 1. `drizzle-orm` `<0.45.2` (HIGH)
- Pinned at `^0.36.0` in `apps/web` and `packages/core`.
- **Out of scope for this PR** per founder directive ("upgrade Next.js and NextAuth only; do not mix with other changes").
- **Follow-up PR needed**: bump to `^0.45.2`. Risk: schema/migration code uses Drizzle; needs schema-level regression test. Estimated effort: half day.

### 2. `postcss` `<8.5.10` (MODERATE, transitive)
- Comes via `next@15.5.20 > postcss@8.4.31` in `next-auth@5.0.0-beta.31 > @auth/core > jose`.
- Direct dep in `apps/web/package.json` is `^8.5.16` (devDep only, not used in production bundle).
- Next.js team has not updated their internal postcss in 15.5.x.
- **Options**:
  - (a) Wait for Next.js 15.5.21+ to bump their internal postcss.
  - (b) Add `pnpm.overrides` for `postcss` to force `^8.5.10` — but this can break Next's build pipeline.
  - (c) Use `next-transpile-modules` and rebuild — too invasive for this sprint.
- **Recommended**: (a) — wait one minor Next release. Track as a follow-up issue.
