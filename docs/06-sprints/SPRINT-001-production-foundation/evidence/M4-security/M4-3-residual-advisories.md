### 4.2 Bumping drizzle-orm 0.36 → 0.45 — API surface used by this repo

A manual scan of `packages/core/src` for `drizzle-orm` usage:

- `import { drizzle, type NodePgDatabase } from "drizzle-orm/node-postgres"` (`db/client.ts`)
- `import { and, eq } from "drizzle-orm"` (`api/index.ts`)
- `import { eq, sql } from "drizzle-orm"` and `import type { NodePgDatabase } from "drizzle-orm/node-postgres"` (`auth/credentials.ts`)
- `import { sql } from "drizzle-orm"` and `from "drizzle-orm/pg-core": boolean, check, index, pgTable, text, timestamp, uniqueIndex, uuid` (`db/schema/identity.ts`)

Public methods used: `db.select(...).from(...).where(...)`, `.limit(1)`, `.insert(...).values(...).returning()`, `.update(...).set(...).where(...)`, and the schema-level `.references(...)`, `.defaultRandom()`, `.defaultNow()`, `.notNull()`, `.primaryKey()`. **All of these are stable across 0.36 → 0.45+**; the breaking changes in that range were around `relations()`, the new `prepared queries` API, and `drizzle-kit` output (which we use only via `db:generate`).

### 4.3 `pnpm.overrides` for postcss

Direct devDep `postcss@^8.5.16` in `apps/web` is already past the patched range. The advisory hits `next@15.5.20 > postcss@8.4.31` (transitive). The cleanest fix is a pnpm override at the workspace root:

```json
"pnpm": {
  "overrides": {
    "postcss": "^8.5.10"
  }
}
```

This forces every `postcss` (direct or transitive) in the workspace to a patched version. Risk: if `next` requires a specific internal `postcss` shape, this could break the build. Mitigation: `pnpm verify` must stay green; if the override breaks Next's pipeline, fall back to "wait for Next 15.5.21+ and re-capture audit" (the original M4.1 recommendation).

## 6. Rollback (ADR-0013 §30, §55)

- `git revert <commit>` restores the prior version pins. `pnpm install --frozen-lockfile` re-resolves. If the override breaks Next, drop the override on revert (the override is a small block in `package.json`). No DB migration, no data backfill. Worst case: M4.3 advisories reappear, service stays up.
