# De-AI & Rebrand Migration Checklist

Goal: zero trace of AI-tool names (Claude/ChatGPT/Codex/Cursor/Gemini/Copilot/Anthropic/OpenAI,
"AI Project OS", "AI-native", "Engineering OS/EOS/OS" branding, AGENTS.md/CLAUDE.md/copilot/.cursor)
**and** zero trace of the "Learning Platform" brand (full rebrand to "Learning Platform", package scope
`@hawza/*` → `@learning-platform/*`, docker/seed creds) — anywhere in the repo, including
append-only history.

Governing engineering choices:
- Work proceeds on branch `chore/de-ai-and-rebrand` (off `fix/m4-authz-data-leak` HEAD, which is
  ahead of main with the M4 security work — do not rebase onto main and drop the fixes).
- Frozen audit artifacts (`docs/06-sprints/.../evidence/M4-security/audit-*.json`,
  `M1-baseline/output-build.txt`) are historical snapshots — left untouched (they bear the old
  package name in a binary log; safe, not surfaced, not editable as prose).
- `pnpm-lock.yaml` is **not** hand-edited — regenerated by `pnpm install` after `package.json`
  renames (phase 5).
- Governance validator (`scripts/governance/**`) reads NONE of the deleted AI-tool files, so
  phases 2–4 cannot break governance CI. The only CI risk is `pnpm verify` (lint/typecheck/test/
  build), which is driven by `@hawza/*` import paths — phase 2 updates every one of them in-phase.
