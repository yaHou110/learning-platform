# De-AI and Rebrand Migration Checklist

Goal: zero trace of AI-tool names (ChatGPT, Claude, Claude Code, Codex, Cursor, Gemini, Copilot, Anthropic, OpenAI, AI Project OS, AI-native, Engineering OS, EOS, OS branding, AGENTS.md, CLAUDE.md, copilot-instructions, .cursor rules) and zero trace of the old brand anywhere in the repo, including append-only history, renamed to Learning Platform with package scope @learning-platform and docker/seed creds.

Governing engineering choices:

- Work proceeds on branch chore/de-ai-and-rebrand (off fix/m4-authz-data-leak HEAD, which is ahead of main with the M4 security work; do not rebase onto main and drop the fixes).
- Frozen audit artifacts (audit-baseline.json, audit-after.json, audit-after-2.json, output-build.txt) are historical snapshots and are left untouched. They bear the old package name inside a binary pnpm audit path but are not surfaced and not editable as prose.
- pnpm-lock.yaml is not hand-edited; it is regenerated by pnpm install after the package.json renames (phase 5).
- Governance validator (scripts/governance) reads none of the deleted AI-tool files, so phases 2 through 4 cannot break governance CI. The only CI risk is pnpm verify (lint, typecheck, test, build), which is driven by the package-scope import paths; phase 2 updates every one of them in-phase.
